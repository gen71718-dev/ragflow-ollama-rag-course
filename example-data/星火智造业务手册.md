# 星火智造（上海）科技有限公司 产品与售后手册

## 一、公司简介
星火智造（上海）科技有限公司成立于2015年，总部位于上海市浦东新区张江高科技园区，是一家专注于工业物联网设备研发、生产和销售的高新技术企业，现有员工320人。公司主要客户为长三角地区的制造工厂和物流园区。

## 二、主营产品
1. XH-100 温湿度传感器：测量范围 -20℃ 至 80℃，精度 ±0.3℃，单价 260 元。
2. XH-200 智能网关：支持 4G 与 WiFi 双通道，最多可接入 64 个传感器节点，单价 1280 元。
3. XH-300 烟雾报警器：支持本地声光报警和平台推送，单价 180 元。
4. XH-500 工业数据采集终端：防护等级 IP65，工作温度 -40℃ 至 85℃，单价 3200 元。
5. 云平台年服务费：每台设备每年 100 元，包含数据存储与基础告警功能。
